## ✨ Features

- **Premium Design Aesthetics**: Inspired by high-end minimalist portfolios.
- **Dark Mode Support**: Seamless transition between light and dark themes.
- **Dynamic Content**: Blog and experiences managed via structured data.
- **Responsive Layout**: Optimized for all devices from mobile to ultra-wide screens.
- **Performance Focused**: Built with Next.js App Router for optimal speed.
- **Micro-animations**: Subtle interactions for an enhanced user experience.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Iconify](https://iconify.design/)
- **Typography**: [Geist Sans](https://vercel.com/font)
- **Deployment**: [Vercel](https://vercel.com/)

## 📂 Project Structure

## 🚀 Getting Started

### Prerequisites

- Node.js (Latest LTS)
- npm or pnpm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/joypaul3592/portfolio.git
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the development server:

   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) to see the result.
